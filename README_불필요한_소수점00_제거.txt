불필요한 .00 표시 제거 업데이트

목적
- 3000.00 -> 3000
- 25.00   -> 25
- 12.50   -> 12.5
- 12.34   -> 12.34

즉 실제 소수값은 유지하고 뒤에 불필요하게 붙는 0만 제거합니다.

적용 대상
- 대시보드 재고 수량
- 콩 재고/사용량/포대수
- 월 매출 수량
- 단가관리의 단가 입력값
- 판매내역 수량/단가 입력값
- 이익관리 비용 입력값 및 사용량
- 행사단가 입력값
- 엑셀 업로드 미리보기 수량/회수통 단가

금액 합계처럼 이미 "3,000원"으로 표시되던 부분은 그대로 유지합니다.

주의
- DB 자료형/저장값은 변경하지 않습니다.
- 계산 로직도 변경하지 않습니다.
- 화면에 보여줄 때만 불필요한 0을 제거합니다.
- 위도/경도는 정밀도가 필요하므로 건드리지 않았습니다.

적용
1. 서버 종료 Ctrl+C
2. 압축의 src 폴더를
   F:\bean_sprout\salesmgmt
   에 덮어쓰기
3. 실행
   cd F:\bean_sprout\salesmgmt
   .\gradlew.bat clean bootRun
4. 브라우저 Ctrl+F5

Java 변경 없음.
