네이버 지도 위치 자동저장 수정

기존 문제
- "주소로 위치찾기"를 누르면 지도에는 즉시 표시됐지만
  DB에 저장되지는 않았습니다.
- 별도로 거래처 행의 "저장" 버튼을 눌러야 했습니다.
- 저장하지 않고 페이지를 다시 열면 마커와 빨간 선이 사라졌습니다.

수정 후
1. 주소 입력
2. "주소로 위치찾기" 클릭
3. 네이버 Geocoder가 위도/경도를 찾음
4. 해당 거래처 행 전체를 자동 저장
5. 페이지 자동 새로고침
6. 저장된 좌표로 마커/빨간 선이 처음부터 표시

"지도에서 찍기"도 동일합니다.
- 지도에서 위치 클릭
- 자동 저장
- 다음 접속에도 위치 유지

중요
- 기존에 주소만 저장하고 좌표는 저장하지 않았던 거래처는
  이번 업데이트 적용 후 딱 한 번씩 "주소로 위치찾기"를 눌러주세요.
- 그 한 번 이후에는 다시 누를 필요 없습니다.

적용
1. 서버 종료: Ctrl + C
2. 압축의 src 폴더를
   F:\bean_sprout\salesmgmt
   에 덮어쓰기
3. 실행:
   cd F:\bean_sprout\salesmgmt
   .\gradlew.bat clean bootRun
4. 브라우저 Ctrl + F5
5. /vendors 접속
