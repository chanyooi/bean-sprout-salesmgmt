단가 관리 업데이트 적용 방법

1. 실행 중인 서버를 종료합니다.
   - 터미널에서 bootRun 중이면 Ctrl+C

2. 이 압축파일 안의 build.gradle과 src 폴더를
   F:\bean_sprout\salesmgmt 폴더에 복사하고 덮어씁니다.

3. application.yml은 이 압축파일에 들어 있지 않습니다.
   기존에 설정한 MySQL 비밀번호는 그대로 유지됩니다.

4. IntelliJ 오른쪽 Gradle 창에서
   Reload All Gradle Projects를 누릅니다.

5. IntelliJ 터미널에서 실행합니다.

   cd F:\bean_sprout\salesmgmt
   .\gradlew.bat clean bootRun

6. 브라우저에서 접속합니다.

   http://localhost:8080/prices

7. template.xlsx를 선택하고 먼저
   '추출 결과 확인'을 누릅니다.

8. 결과에서 아포농협, 팔공식품, 일반 거래처 단가를 확인한 뒤
   '확인 후 단가 저장'을 누릅니다.

9. 저장 후 아래 주소에서 판매단가와 금액을 확인합니다.

   http://localhost:8080/sales

동작 규칙

- 0원으로 되어 있는 템플릿 단가는 미등록으로 보고 건너뜁니다.
- 기존 판매 데이터 중 단가가 비어 있는 행만 자동으로 채웁니다.
- 이미 판매단가가 들어 있는 과거 판매 행은 바꾸지 않습니다.
- 명희네 템플릿은 입력 거래처명 '명희네해장'에 연결됩니다.
- 두절1kg은 두절kg으로 연결됩니다.
- 일반(소)콩나물은 일반콩나물로 연결됩니다.
- 일반소콩나물은 소립으로 연결됩니다.
- 일반 거래처의 회수통 단가는 회수통현황 아래 단가에서 읽습니다.
- 팔공식품의 손두부·두부판은 오른쪽 두부품목 영역에서 읽습니다.
