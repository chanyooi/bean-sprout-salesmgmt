통합 업데이트
1. 행사/임시단가 기록
2. 배송코스 최적순서 추천
3. 문자 명세서 대상/발송이력 + 이미지 바로 공유

============================================================
1. 행사/임시단가
============================================================
주소:
http://localhost:8080/promotions

추천 방식:
- 평소 기본단가는 /prices에 그대로 유지
- 행사 발생 시 거래처/품목/기간을 기록
- 행사단가가 아직 미정이면 단가 없이 기록 가능
- 단가 확정 후 행사 이력에서 단가 저장
- "기존 판매에 반영" 클릭
- 해당 거래처 + 품목 + 행사기간의 판매단가만 일괄 변경
- 이후 같은 기간 input_data를 재업로드해도 행사단가가 자동 적용됨

따라서 월말마다 평소 기본단가 자체를 행사단가로 바꿀 필요가 없습니다.

마감된 월:
- 행사단가 일괄반영 차단
- 먼저 /admin/safety 에서 마감 해제 필요

새 테이블:
sales_promotions

============================================================
2. 배송코스 최적순서 추천
============================================================
주소:
/vendors

배송 순서 관리에:
[최적순서 추천]
버튼 추가.

동작:
- 현재 1번 거래처를 출발점으로 고정
- 활성 거래처 전체 좌표 확인
- 직선거리 기반 nearest-neighbor + 2-opt로 순서 추천
- 현재 순서와 추천 순서를 NAVER Directions 15 실제 도로거리로 각각 검증
- 현재 km -> 추천 km / 절약 km 표시
- "추천순서 적용"을 눌러야 DB에 저장
- 자동으로 바로 바꾸지 않으므로 눈으로 확인 가능

주의:
- 전역 최단경로를 수학적으로 보장하는 TSP solver는 아님
- API를 수백 번 호출하지 않고 실무적으로 빠르게 계산하는 휴리스틱
- 현재 1번 거래처는 출발점으로 고정
- 모든 활성 거래처의 지도 좌표가 필요
- 실제 공장 출발점까지 포함하려면 다음에 "공장 위치"를 별도로 등록하면 더 정확하게 개선 가능

Directions 15:
- 경유지 최대 15개에 맞춰
  한 API 요청당 최대 17개 정류장(start+15 waypoints+goal)으로 분할

============================================================
3. 문자 명세서
============================================================
주소:
http://localhost:8080/statement-send

먼저 매달 문자로 명세서를 보내는 거래처만 등록.

목록에서:
[명세서 열기]
-> /statement-export

명세서 화면:
[이미지로 바로 공유]

지원되는 휴대폰 브라우저에서는:
- 명세서 PNG를 메모리에 생성
- 파일을 네이티브 공유창으로 바로 전달
- 문자/카톡 등 공유대상 선택
- 거래처 전화번호가 있으면 클립보드 복사 시도
- 공유가 성공하면 이번 달 "발송완료" 자동 기록

파일 공유 미지원 브라우저:
- PNG 자동 다운로드로 대체
- 전화번호 복사

완전 자동 MMS 발송은 포함하지 않음.
그 기능은 별도 문자 API + 발신번호 인증 + 사용료가 필요합니다.

새 테이블:
statement_delivery_settings
statement_delivery_logs

1. 서버 종료 Ctrl+C
2. 압축의 src 폴더를

4. 브라우저 Ctrl+F5
