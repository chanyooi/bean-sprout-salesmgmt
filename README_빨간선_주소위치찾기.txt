빨간 선이 안 보이는 원인
- 코스와 순서는 저장됐지만 주소만 있고 위도/경도 좌표가 비어 있었습니다.
- 지도는 주소 문자열이 아니라 좌표를 이용해 점과 선을 그립니다.
- 같은 코스에서 좌표가 있는 거래처가 2곳 이상이어야 빨간 선이 생깁니다.

이번 수정
- 주소 아래 "주소로 위치찾기" 버튼 추가
- 주소를 좌표로 검색
- 지도에 점과 빨간 선 즉시 미리보기
- 행의 "저장"을 누르면 좌표가 DB에 저장
- 기존 "지도에서 찍기"도 클릭 즉시 빨간 선 미리보기
- A코스 / B코스 / 김천코스 모두 동일하게 동작

사용
1. 코스 선택
2. 방문순서 입력
3. 주소 입력
4. 주소로 위치찾기
5. 위치가 맞는지 지도 확인
6. 해당 행의 저장 클릭

적용
1. Ctrl+C
2. 압축의 src 폴더를 F:\bean_sprout\salesmgmt 에 덮어쓰기
3. .\gradlew.bat clean bootRun
4. 브라우저 Ctrl+F5
5. /vendors 확인
