판매내역 수정·삭제 업데이트

추가 기능
1. /sales 화면에서 조회 월 선택
2. 거래처별 필터
3. 판매 수량 직접 수정
4. 판매 당시 단가 직접 수정
5. 수량 × 단가 금액 자동 재계산
6. 품목 한 건 삭제
7. 주문 전체 삭제
8. 마지막 품목 삭제 시 빈 주문 자동 삭제
9. 표시 매출, 주문 수, 단가 미등록 건수 요약

적용 방법
1. 실행 중인 서버를 Ctrl+C로 종료
2. 압축을 풀어 src 폴더를 프로젝트 루트에 덮어쓰기
3. 아래 명령으로 다시 실행
   cd F:\bean_sprout\salesmgmt
   .\gradlew.bat clean bootRun
4. 브라우저에서 http://localhost:8080/sales 접속

주의
- 주문 전체 삭제는 해당 주문의 모든 품목을 삭제합니다.
- 삭제한 데이터는 자동 복구되지 않습니다.
- 엑셀에 자료가 남아 있다면 다시 업로드하여 복구할 수 있습니다.
- application.yml, build.gradle, 기존 DB 구조는 변경하지 않습니다.
