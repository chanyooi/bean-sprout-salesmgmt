송천 특수품목 회계 V2

최신 기준

1. 회수통
- 품목별 판매 표에 다시 표시
- 회수통 금액을 월매출에 그대로 반영
- 별도 "보증금·회수 항목" 카드 제거

2. 손두부
- 기존 "매입·재판매 품목" 카드 제거
- 제목은 "손두부"
- 위 품목별 판매와 비슷한 한 줄 표 형태

열:
품목 / 판매 수량 / 판매매출 / 팔공 매입원가 / 판 반납 / 총 반영 매출 / 이익

3. 두부판
- 일반 품목별 판매에서는 제외
- 손두부 계산에 포함
- 판 반납 수익: 1판당 +2,000원
- DB의 "두부판" 수량을 반납한 판 수로 사용

손두부 총 반영 매출:
아포농협 손두부 판매매출 + (두부판 반납 수량 × 2,000원)

손두부 이익:
손두부 총 반영 매출 - 팔공 손두부 매입원가

4. 월매출
- 일반 판매 품목
- 회수통 금액 포함
- 손두부 판매매출 포함
- 손두부 판 반납 수익 포함
- 기존 두부판 행 금액 자체는 제외하고 2,000원/판으로 재계산

적용:
powershell -ExecutionPolicy Bypass -File .\songcheon-special-item-accounting-v2\apply-special-item-accounting-v2.ps1

빌드:
.\gradlew.bat clean build -x test
