배송코스 순서 드래그 자동정렬 업데이트

문제
기존에는
1, 2, 3, 4, 5...
방문순서를 숫자로 직접 입력했기 때문에
중간에 새 거래처를 넣으면 뒤 거래처 번호를 전부 직접 바꿔야 했습니다.

수정 후

1. 새 거래처 추가
- 거래처 정보에서 A코스/B코스/김천코스만 선택
- 저장
- 해당 코스의 가장 마지막 순번으로 자동 추가

예:
기존 B코스 1~24
새 거래처를 B코스로 저장
-> 자동 25번

2. 중간 삽입
배송 순서 관리에서
새 거래처를 3번 위치로 드래그

기존:
1 A
2 B
3 C
4 D
...
25 새 거래처

변경:
1 A
2 B
3 새 거래처
4 C
5 D
...

뒤 번호는 모두 자동으로 +1 됩니다.

3. 기존 거래처 이동
아무 거래처나 잡아서 다른 위치로 이동
-> 1부터 전체 자동 재번호
-> DB 자동 저장
-> 페이지 다시 로드
-> 지도 마커 번호/빨간 선도 새 순서로 표시

4. ↑ / ↓ 버튼
드래그가 불편하면 각 거래처 오른쪽의
↑ ↓ 버튼으로 한 칸씩 이동할 수 있습니다.
버튼을 누른 뒤에도 자동 저장됩니다.

5. 코스 변경
예:
B코스 거래처를 A코스로 변경하고 저장
- B코스에서 자동 제거
- B코스 빈 번호 자동 당김
- A코스 맨 뒤에 자동 추가
- 이후 A코스 순서관리에서 원하는 위치로 드래그

방문순서 숫자 입력
- 거래처 표의 '순서'는 읽기 전용으로 변경
- 숫자를 직접 관리할 필요 없음

DB
- 새 테이블 없음
- 기존 vendor_profiles.route_order 그대로 사용
- DB 구조 변경 없음

적용

   Ctrl + C

2. 압축의 src 폴더를
   F:\bean_sprout\salesmgmt

3. 실행
   cd F:\bean_sprout\salesmgmt
   .\gradlew.bat clean bootRun

4. 브라우저에서

   http://localhost:8080/vendors

테스트 권장
- B코스에서 순서가 뒤쪽인 거래처 하나를 3번째 위치로 이동
- 페이지가 자동 새로고침된 뒤 번호가 1,2,3,4...로 정렬됐는지 확인
- 지도 B코스의 마커 번호와 빨간 선 순서도 같이 바뀌었는지 확인

application.yml 변경 없음
build.gradle 변경 없음
MySQL 스키마 변경 없음
