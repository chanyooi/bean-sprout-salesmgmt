거래명세서 회수통 수식 오류 수정

문제
다운로드된 명세서에서 빈 날짜에도 합계가 -33,000원처럼 표시됨.
수식 예:
=I30*6000+H30*5000+G30*4500+E30*15000+D30*13000+C30*1800-33000

원인
template1 호환 코드에서 원래 템플릿의
-F30*3000
같은 회수통 수식을 삭제하고 DB의 회수통 금액을
-33000
같은 고정 숫자로 넣는 로직이 있었음.

수정
고정 금액으로 수식을 바꾸는 로직을 완전히 제거합니다.

정상 수식 예:
=I30*6000+H30*5000+G30*4500+E30*15000+D30*13000+C30*1800-F30*3000

이제 회수통 수량이 0/빈칸이면 자동으로 0원 차감되고,
회수통 수량이 있을 때만 수량 × 3,000원이 차감됩니다.

적용:
powershell -ExecutionPolicy Bypass -File .\songcheon-statement-return-formula-fix\apply-return-formula-fix.ps1

빌드:
.\gradlew.bat clean build -x test

테스트:
거래명세서 다운로드 후 빈 날짜 합계가 0원인지 확인합니다.
