거래처 명세서

거래명세서 생성

MySQL에 저장된 판매 수량을 등록된 거래명세서 템플릿에 넣어 완성된 월간 명세서를 다운로드합니다.

엑셀 거래명세서 만들기

판매가 없는 거래처의 빈 명세서도 기본으로 포함됩니다.
팩스·우편·문자 버튼은 거래처 관리에서 지정한 전달 방식에 맞는 거래처 시트만 따로 저장합니다.

기본 템플릿 관리

명세서 양식을 바꿀 때만 새 .xlsx 파일을 등록하면 됩니다.

현재 기본 템플릿: template.xlsx

등록한 템플릿은 전체·팩스·우편·문자·거래처별 개별 명세서에 계속 사용됩니다.

생성 기준

일반 거래처

선택한 달의 1일부터 말일까지 날짜별 판매 수량을 입력합니다.

선산식자재마트

전달 26일부터 선택한 달 25일까지를 한 달 정산기간으로 처리합니다.

전달 방식별 파일

거래처 관리에서 팩스·우편·문자로 분류하면 해당 방식 거래처 시트만 모아서 다운로드합니다.

빈 명세서 포함

판매가 없는 거래처도 기본으로 포함해 전체 거래처 명세서를 만들 수 있습니다.

확인할 점

아직 전달 방식이 미분류인 거래처는 전체 엑셀에는 포함되지만 팩스·우편·문자 분류 다운로드에는 포함되지 않습니다.
