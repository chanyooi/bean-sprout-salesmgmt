거래명세서 생성

MySQL에 저장된 판매 수량을 등록된 거래명세서 템플릿에 넣어 완성된 월간 명세서를 다운로드합니다.

홈(대시보드) PDF·이미지·공유 발송 기록

엑셀 거래명세서 만들기

새 .xlsx 파일을 선택하고 아래 다운로드 버튼을 누르면 템플릿 구조를 검사한 뒤 앞으로 사용할 기본 템플릿으로 저장됩니다. 다음부터는 파일을 다시 선택할 필요가 없습니다. 현재 기본 템플릿: template.xlsx
팩스·우편·문자 버튼은 거래처 관리에서 지정한 명세서 전달 방식에 맞는 거래처 시트만 따로 저장합니다.

생성 기준

일반 거래처

선택한 달의 1일부터 말일까지 날짜별 판매 수량을 입력합니다.

선산식자재마트

전달 26일부터 선택한 달 25일까지를 한 달 정산기간으로 처리합니다.

전달 방식별 파일

거래처 관리에서 팩스·우편·문자로 분류하면 해당 방식 거래처 시트만 모아서 다운로드합니다.

기본 템플릿

새 템플릿을 한 번 등록하면 전체·팩스·우편·문자·거래처별 개별 다운로드에 계속 같은 양식을 사용합니다.

확인할 점

아직 전달 방식이 미분류인 거래처는 전체 엑셀에는 포함되지만 팩스·우편·문자 분류 다운로드에는 포함되지 않습니다.
